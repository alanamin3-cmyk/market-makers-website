# Market Makers Co. Website

Static website for Market Makers Co., a pharmaceutical commercialization and market-access partner in Iraqi Kurdistan.

## Files

- `index.html` - main website page
- `styles.css` - visual design and responsive layout
- `script.js` - small header scroll behavior
- `assets/` - website logo, brand image, and font assets used by the page

## Publishing

This is a static website. It can be hosted with GitHub Pages from the repository root.
